### Saved settings

The Customizer panel has a preset bar above the sections: the **+** button saves your current values as a named set inside a JSON file next to the `.scad` file. The sets that ship with the project are in [`{presets_json}`](../../../{presets_json}). They are plain text: easy to keep, compare and share.
