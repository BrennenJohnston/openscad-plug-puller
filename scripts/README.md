# scripts/

Utility scripts used to build and validate the Plug Puller model's committed artifacts. All paths are relative to the repo root; run them from there, e.g. `python scripts/build_flattened.py`.

## Contents

| Script | Purpose |
|--------|---------|
| `build_flattened.py` | Deterministically inline each model's include tree into its single-file artifact for web customizers (MakerWorld PMM, openscad-playground `?src=` loading): `dist/Plug_Puller_SingleFile.scad` from `src/Plug_Puller_Parametric.scad` (inlines `src/fit_sizes.scad`, `src/fit_measured.scad` and `src/presets.scad`) and `dist/Plug_Puller_Two_Sided_SingleFile.scad` from `src/Plug_Puller_Two_Sided.scad` (inlines `src/fit_sizes.scad`); `--check` verifies both are fresh (CI does this on every run). |
| `regenerate_fixtures.py` | Re-render every golden STL under `tests/fixtures/<name>/reference.stl` from its `params.json`, and refresh the matching `metadata.json` with OpenSCAD version + trimesh measurements. Run after any intentional SCAD change so the mesh-comparison tests in `tests/test_render_modes.py` keep validating actual deltas, not stale references. |
| `build_release_stls.py` | Render the committed ready-to-print library under `stl/`: 9 plug tools in `stl/Plug-Puller/` (6 one-sided pullers for the lamp and standard plug presets × 3 hand sizes, and 3 two-sided pullers for the round extension cord × 3 hand sizes, both plates in each file) + 16 measuring-stencil cards (Visual/Tactile full sets and individual cards, in `stl/Measuring-Stencil/`). Each output is watertight-checked. Run after any intentional model change and commit the refreshed `stl/`; `tests/test_shipped_stls.py` reuses this script's job catalog to guard the shipped files. Use `--only plug-puller` / `--only stencil` to rebuild one group. |
| `generate_outline_sheets.py` | Generate the try-before-you-print outline sheets (`docs/guides/outline-sheets/`, 9 SVGs): render each quick-select combination (the lamp and standard plug presets × 3 sizes for the one-sided puller, plus one two-sided puller plate at 3 sizes) via the OpenSCAD CLI, extract the true 1:1 silhouette / through-holes / pocket opening with trimesh + shapely, compute the labeled dimensions from `tests/fit_formulas.py`, and compose A4/Letter SVG sheets with CAD dimension lines and a calibration square. Asserts dimension parity between the mesh, the formulas, and the sheet before writing. Re-run after any geometry or preset change. |
| `build_outline_sheets_pdf.py` | Bundle the 9 outline-sheet SVGs into the printable `docs/Plug_Puller_Outline_Sheets.pdf` (cover/index page + one sheet per page) via headless Edge/Chrome — the same Skia print pipeline as the other PDF guides. The `@page` size equals the SVG page (210 × 279 mm) so the sheets keep their exact 1:1 scale; the script verifies the page count and every page's MediaBox after printing. Run after `generate_outline_sheets.py`. |
| `generate_stencil_sheet.py` | Emit `docs/guides/stencil-sheet.svg`, the 1:1 paper alternative to the 3D-printable `Measuring_Stencil.scad`: one 210 × 279 mm page with the 50 mm calibration square, the P1–P3 plug silhouettes, a 100 mm ruler, and the 18 finger circles. Its `PLUG_PRESET_DIMS` constant is drift-tested against both SCAD files by `tests/test_stencil_data.py`. Re-run after any preset-dimension change. |
| `build_starter_guide_pdf.py` | Build the printable `docs/Plug_Puller_Starter_Guide.pdf`: the starter guide (`docs/guides/starter-guide.md`) condensed onto two typeset pages, plus the stencil sheet SVG as the final page at exact 1:1 scale. Reuses the outline-sheets print/verify pipeline. Run after `generate_stencil_sheet.py`. |
| `generate_dial_diagrams.py` | Draw one diagram per Customizer dial under `docs/dials/` from `dial_catalog.json` (reads the two parameter mappings for the defaults): each row is rendered twice via the OpenSCAD CLI (the defaults plus the row's context, then the dial at its `after` value), the top view is extracted with the outline-sheet helpers (shadow silhouette, through-holes and pocket recess for the one-sided puller; the contact-face section for a two-sided plate), and the symmetric difference becomes the red dashed trace over the black default outline and the teal plug. Writes `docs/dials/one-sided/<name>.svg`, `docs/dials/two-sided/<name>.svg` (1 unit = 1 mm, with `<title>` / `<desc>` text equivalents; "no shape" rows get a 120 × 40 mm card) and `docs/dials/dial_diagrams_index.json` (values, region count, changed area, warning tags and the named features the trace touches, per dial), then `docs/dials/README.md` (every diagram inline with its sentence as alt text; `--readme` rewrites it alone from the index). Renders are cached under `tmp_renders/dial_diagrams/` (keyed by the parameter set and the SCAD sources; `--force` re-renders). `--file`, `--only NAME` and `--views {top,none,section,all}` limit a run. A full forced run of all 118 rows is 214 renders, about 6 minutes on the reference PC (measured 2026-09-26: the 89 top rows 4 min 43 s with 148 s inside OpenSCAD, the 18 section rows 39 s); a cached run of every row about 3 minutes. |
| `build_dial_reference.py` | Build the dial reference from `dial_catalog.json`, both parameter mappings and `docs/dials/dial_diagrams_index.json`: the Markdown twin `docs/guides/dial-reference.md` (H4 per dial with its diagram, sentence, default / range / step / unit, note, the features it moves and the warning tags it can trip, from a hand-kept table read off `docs/guides/fit-troubleshooting.md`) and `docs/Plug_Puller_Dial_Reference.pdf` (a title page, a two-page linked contents, one page per dial; 121 pages, about 7 MB) printed with headless Edge through `build_outline_sheets_pdf.print_to_pdf` with the document outline on and a scratch profile under `tmp_renders/edge_profile/`, then verified (page count, page box, 122 outline entries, at least 118 link annotations). `--quick` builds the quick-start cut instead (`docs/guides/dial-quick-start.md` and `docs/Plug_Puller_Dial_Quick_Start.pdf`: an opener page saying which file to open, then the 28 Steps 1–4 dials; 30 pages, about 2.2 MB); `--markdown-only` needs no browser. Run both after `generate_dial_diagrams.py`. |
| `render_doc_images.py` | Render the three preview PNGs the guides embed, from today's model files with the canonical OpenSCAD binary: `docs/images/one-sided-medium-render.png` (the one-sided puller at its defaults), `docs/images/two-sided-plate-render.png` (both plates of the two-sided puller at its defaults) and `docs/images/one-sided-warning-tag-preview.png` (a 27 mm thick plug, so the W-20 warning's red text lies beside the part; a plain PNG export is a preview, so the see-through plug and the tags show). Standard library only; `--only NAME` renders one. Re-run after a model change that moves what these pictures show. |

## Prerequisites

- Python 3.11+ with the dev dependencies installed: `pip install -r requirements-dev.txt`
- OpenSCAD 2026.01.03+ nightly (Manifold backend) on `PATH`, or set `OPENSCAD_PATH` — needed by `regenerate_fixtures.py` and `generate_outline_sheets.py`.
- Microsoft Edge or Chrome — needed by `build_outline_sheets_pdf.py` and `build_starter_guide_pdf.py` for headless SVG-to-PDF printing.
